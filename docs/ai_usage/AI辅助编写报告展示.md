- 一页讲难点
- 一页讲 CKA
- 一页讲 LoRA
- 一页讲量化
- 一页讲某项实验

这比一页塞太多信息更适合答辩。

### 3. 标题格式很统一
大部分页都采用：

**“大章节——子主题”**

例如：

- 赛题分析——题目核心要求分析
- 赛题分析——相关技术调研
- 背景知识——CKA相似性分析
- 稀疏化——动态分配稀疏度
- 实验——核心模块验证

这会让全篇非常整齐。

### 4. 理论页采用“三段式”
理论页的常见结构是：

1. 概念定义
2. 数学公式
3. 性质/结论/为什么有用

这是一种很标准的技术页写法。

### 5. 实验页采用“图表 + 结论先行”
实验页不是只贴图，而是先写 3-4 条解释性结论，再配图。

这很重要。  
因为评委不会自己替你读图，你要直接告诉他：

- 看到了什么
- 这说明什么
- 它支持哪个论点

### 6. 最后收尾不是只放结论
它最后还放了：

- 进度安排
- 问题和解决方法
- 成员分工
- 致谢与参考
- 结束页

这说明它把“项目完成度”作为答辩说服力的重要组成部分。

## 七、如果你要“照着这个报告写别的论文”，最该学什么

我建议重点学这五点：

1. **先给全局结构，再讲复杂细节**  
   评委和读者先看到系统图，再听理论和实现，理解成本会低很多。

2. **每一页或每一节只承担一个任务**  
   不要一节里既讲背景、又讲公式、又讲实验、又讲结论。

3. **理论页一定要“定义 + 公式 + 为什么有用”**  
   只放公式没有解释，评委不会替你补。

4. **实验页一定要“图 + 结论”成对出现**  
   图是证据，结论是解释，缺一不可。

5. **竞赛型报告必须补工程和管理信息**  
   进度、问题、分工、仓库结构，这些不是多余内容，而是“真实性”和“完成度”的证据。
