# AI 工具使用记录

本目录用于保存 AstraKV-W 项目在开发、测试、报告整理和答辩材料准备过程中使用 AI 工具的说明与索引。

## 使用工具

- OpenAI Codex / GPT-5

## 使用场景

- 代码仓库结构阅读和模块边界梳理
- DGX Spark 环境安装、提测流程和运行脚本整理
- 单元测试卡住、依赖安装失败、图表异常等工程问题定位
- 实验结果、日志和报告产物的归纳分析
- 实验图表生成、报告正文图整理和证据口径检查
- 测试清单、复现流程和图表说明的整理
- 报告正文、答辩材料大纲和合规检查表的文字草拟与润色

## 不使用范围

- 不由 AI 生成或伪造实验数据
- 不由 AI 替代 DGX Spark 真实实验执行
- 不将 AI 输出直接视为性能结论，性能结论以仓库代码、脚本日志和结构化 artifact 为准
